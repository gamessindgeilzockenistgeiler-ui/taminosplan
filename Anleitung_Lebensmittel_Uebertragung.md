# 02 // SO ÜBERTRÄGST DU JEDES LEBENSMITTEL INS SYSTEM (3 METHODEN)

Dein neues **PERFORMANCE OS v4.0** hat bereits **266 kuratierte Alltags-Lebensmittel** offline gespeichert. Für alles Weitere hast du direkt im Dashboard (`Tab 02 // Rezept-Studio`) und im `Tab 03 // Lebensmittel-Datenbank` drei Profi-Methoden eingebaut:

## 🌐 Methode 1: Live OpenFoodFacts Web-Suche & Barcode-Scanner
- Klappe im Rezept-Studio **`🌐 Hilfsmethode 1: Live-Suche in öffentlicher Datenbank (OpenFoodFacts API)`** auf.
- Tippe irgendein Supermarkt-Produkt (z. B. *"Mio Mio Mate"*, *"Dr. Oetker Pizza"*, *"Ehrmann High Protein"*) oder den 13-stelligen Strichcode (EAN) von der Verpackung ein.
- Klicke auf **`Jetzt live auf OpenFoodFacts suchen`** – das Dashboard holt die offiziellen 100g-Nährwerte live von `de.openfoodfacts.org` und überträgt sie mit 1 Klick in dein Rezept und deine lokale Datenbank.

## 📋 Methode 2: Smart Copy-Paste von öffentlichen Nährwert-Webseiten
- Wenn du auf Seiten wie **fddb.info**, **kalorientabelle.net**, **naehrwertrechner.de** oder **yazio.com** nachschaust:
- Markiere einfach den Text mit den Nährwerten auf der Webseite (`Strg+C`) und füge ihn bei **`📋 Hilfsmethode 2: Smart Copy-Paste Übertragung`** ein (`Strg+V`).
- Der eingebaute Parser erkennt automatisch **Kalorien (kcal), Eiweiß/Protein (g), Kohlenhydrate (g) und Fett (g)** und speichert das Lebensmittel sofort ab.

## 📊 Methode 3: CSV / Excel Massen-Übertragung
- Im Tab **`03 // Lebensmittel-Datenbank (266+)`** kannst du ganze Tabellen als `.csv`-Datei mit einem Klick importieren oder nach Excel exportieren.
